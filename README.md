# Pamidi Yesaswini — Portfolio

Personal portfolio website built with React, Vite, and Tailwind CSS.

🔗 **Live site:** https://portfolio-enpzx3y08-yesaswini19s-projects.vercel.app/

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Lucide Icons

## Sections

- About
- Skills
- Projects — MealPrepPro, Smart-Agri-Assistant, College Event System
- Experience
- Certifications
- Education
- Achievements
- Contact

## Run locally

```bash
git clone https://github.com/yesaswini19/portfolio.git
cd portfolio
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build for production

```bash
npm run build
```

Output is generated in the `dist/` folder.

## Deployment

Deployed on [Vercel](https://vercel.com). Every push to `main` auto-redeploys.
